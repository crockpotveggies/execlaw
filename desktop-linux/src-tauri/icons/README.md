# Rendered icon set

This directory is the output sink for icons generated by
`scripts/build-linux.sh`. Nothing in here is committed —
everything renders from the SVG source at the repo's top-level
`/assets/execlaw-color.svg` on every build.

Expected files after a successful build:

- `32x32.png`, `128x128.png`, `128x128@2x.png` — standard Tauri /
  freedesktop.org icon sizes the .deb bundler installs into
  `/usr/share/icons/hicolor/<size>/apps/execlaw.png` (and the
  256-px slot derived from `128x128@2x`).
- `icon.png` — 512 px source for `bundle.icon`; Tauri uses it as
  the runtime WebView window icon.

The tray app embeds `128x128.png` via
`include_bytes!("../icons/128x128.png")` in `src/app.rs`, so this
file must exist before `cargo build` runs.

If the build fails complaining about a missing icon, re-run
`scripts/build-linux.sh` — the icon-render step is its own phase
and a partial build can leave the directory empty.
