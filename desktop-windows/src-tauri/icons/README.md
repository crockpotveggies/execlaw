# Rendered icon set

This directory is the output sink for icons generated by
`scripts/build-windows.ps1`. Nothing in here is committed —
everything renders from SVG sources under the repo's top-level
`/assets/` directory on every build.

Expected files after a successful build:

- `icon.ico` — the multi-resolution app icon embedded by Tauri's
  bundler (16/32/48/64/128/256 px slots).
- `icon.png` — 1024 px PNG used by `tauri.conf.json`'s
  `bundle.icon` runtime window-icon path.
- `tray.ico` — 16/32 px taskbar / notification-area icon embedded
  into the binary via `include_bytes!("../icons/tray.ico")` in
  `src/app.rs`.

If the build fails complaining about a missing `icons/icon.ico`,
re-run `scripts/build-windows.ps1` — the icon-render step is its
own phase and a partial build can leave the dir empty.
